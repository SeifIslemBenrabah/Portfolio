# Seif Islem Benrabah — Portfolio

Personal portfolio site for Seif Islem Benrabah, Creative Designer & Developer.

Live: https://seifislembenrabah.github.io/Portfolio/

## Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- Framer Motion (`motion/react`)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Pushing to `main` triggers the GitHub Actions workflow in `.github/workflows/deploy.yml`, which builds the site and publishes it to GitHub Pages.
